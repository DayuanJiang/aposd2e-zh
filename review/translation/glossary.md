# 术语表

本表由 `bin/glossary.py` 从 `terms.tsv` 生成，列出译本审校时人工裁定的术语。每一条给出首选译法、它在本书中的义项，
以及使用边界（哪些语境不适用、容易和什么混淆）。首选译法只在注明的义项内适用，不是全局替换规则；
同一个英文词在普通英语义项下仍按上下文翻译。证据位置、词形和已见异译见 `terms.tsv`。
